1. Executive Summary & Brand Overview

Venthulir is an enterprise-ready, high-converting organic e-commerce web platform engineered specifically for traditional wood cold-pressed oils, single-origin farm harvests, and organic grocery items originating from Tamil Nadu.

The platform unifies a customer digital storefront with an administration suite featuring real-time stock control, order fulfillment workflows, automated WhatsApp dispatch links, transactional HTML emails, Razorpay payments, and promotional coupon engines.

3. Database Schema & Architecture (9 Collections)

All database models are located in src/models/ and utilize Mongoose schema validation:

1. Product (ProductDetails)

Fields: productCode (auto VNT-XXXXXX), name, price, originalPrice, discountPercent, variants[], comboContents[], currentStock, initialStock, hsnSac, slug.

2. Order (OrderRegistry)

Fields: customerName, customerEmail, phone, deliveryAddress, items[], totalAmount, paymentMethod, status, trackingNumber, courierPartner.

3. User (CustomerDetails)

Fields: name, email (unique), phone, password (bcrypt), deliveryAddress, isAdmin, otp, otpExpires.

4. Offer (OffersCollection)

Fields: name, price, offerPrice, mrpIllusion, stock, startDate, endDate, badge, virtual computed status.

5. Coupon (Coupons)

Fields: couponCode, discountPercentage, maxUses, usedCount, expiryDate, status.

6. Settings (GlobalSettings)

Fields: storeName, supportEmail, defaultShippingFee, freeShippingThreshold (₹499), enableCOD, enableOnlinePayment, announcementText.

7. OtpStore (Temporary Auth)

Fields: email, otpHash, type, expiresAt. Features a native MongoDB TTL Index (auto-deletes after expiry).

8. Message (ContactInquiries)

Fields: name, email, phone, subject, message, isRead, createdAt.

5. Customer Storefront Features

  • Homepage: Hero banner carousel, limited-stock countdown flash deals, bestseller showcase, brand trust pillars, and customer reviews.
  • Catalog & Filtering: Category tabs (Oils, Grains, Sweeteners, Spices), live multi-attribute search, price sorting, and variant selector dropdowns.
  • Cart & Checkout: Real-time cart drawer with subtotal calculations, live coupon validation, automatic free shipping calculator (> ₹499), and COD/Razorpay selection.
  • Customer Dashboard: Order history timeline with live progress tracking (Pending → Confirmed → Shipped → Delivered), AWB tracking numbers, and saved address book.
  • Authentication Flow: Centered desktop and mobile login card, OTP-based password reset, and session persistence via AuthContext.

6. Admin Panel Management Suite (/admin)

Protected by AdminGuard.jsx which enforces JWT token validation and admin role permissions:

  • Orders Fulfillment: Filter orders by status, input tracking numbers and courier partner names.
  • 1-Click WhatsApp Dispatch: Generates formatted WhatsApp messages with Order ID, item list, courier name, and tracking links to send directly to customers.
  • Printable GST Tax Invoice: Generates official A4 tax invoices with HSN/SAC codes, company details, item breakdowns, and tax rates.
  • Inventory & Low Stock Alerts: Real-time inventory table highlighting products with < 5 units with a 1-click restock modal.
  • Flash Sales & Coupons: Create countdown offers, configure discount percentages, usage limits, and expiration dates.
